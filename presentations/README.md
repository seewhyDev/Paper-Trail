# Paper Trail 발표 자료

- [PowerPoint 슬라이드](Paper-Trail-Presentation.pptx): 편집 가능한 텍스트·흐름도·기술 표와 슬라이드별 발표자 노트
- [발표용 PDF](Paper-Trail-Presentation.pdf): 같은 슬라이드의 레이아웃을 고정한 열람·발표용 사본

본문 14장과 부록 2장으로 구성했습니다. 10~15분 발표를 기준으로 에이전트 개념과 구성 요소, 단순 호출·워크플로와의 차이, Paper Trail의 실행 흐름, 함수 호출, 근거 검증, 시연 순서로 설명합니다. 부록은 사용 기술과 상태 저장·실행 제어를 다룹니다.

PPTX의 글꼴은 macOS의 **Apple SD Gothic Neo**입니다. 해당 글꼴이 없는 발표 환경에서는 PDF를 사용하면 같은 화면을 유지할 수 있습니다. PDF는 렌더링한 슬라이드 이미지로 구성하며 텍스트 편집과 발표자 노트는 PPTX에서 확인합니다.

구현 설명은 2026-09-29의 저장소 코드(`7f5cac7`) 기준입니다. 개념 설명은 [Anthropic의 Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)를 참고했고, 관련 코드·자료 출처는 각 슬라이드의 발표자 노트에 기록했습니다. 실제 논문 모드와 고정 응답·합성 자료를 사용하는 예시 체험을 구분해 설명합니다.
